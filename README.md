# ChatHighlighter

ChatHighlighter is a Minecraft plugin that enhances the chat experience by highlighting messages with colors based on the block a player is looking at. This plugin adds a visual element to the chat, making it more engaging and interactive. The plugin supports a wide range of blocks and assigns each a unique color, providing a vibrant chat environment.

## Install

1. Download the ChatHighlighter plugin JAR file from the [GitHub repository](https://github.com/EnderDevelopment/ChatHighlighter).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. Launch your Minecraft client and connect to the server where the plugin is installed.
2. Look at a block within a 5-block radius.
3. Type a message in the chat.
4. The message will be highlighted with a color corresponding to the block you are looking at.
